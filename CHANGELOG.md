# Changelog

All notable changes to the Komikan Game project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure with UV and Commitizen configuration
- 5x8 grid board game implementation with pygame
- Comprehensive test suite with 71 tests using pytest
- Player movement and capture mechanics
- Debug logging system for game moves and state tracking
- Board validation for disabled nodes and paths
- Asymmetric gameplay (1 vs 12 tokens)
- Mouse and keyboard input controls

### Fixed
- Capture move execution bug in game loop
- Movement validation for capture possibilities
- Test coverage for all board mechanics and edge cases
